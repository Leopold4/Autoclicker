# Autoclicker
Simple autoclicker for simulating rapidly clicking or holding mouse2.

The zip folder is a ready to use app, just unpack it anywhere, if you want to download the .exe and bg.jpg (background image = not required for the app to work) i left it in the download folder too.
The background is customizable, just add any jpg file under the name "bg.jpg" to the folder where the .exe is and remove the standard one.
